# Mellold Tattoo - Bootstrap + JavaScript OO

# Sobre o projeto

Criei esse projeto com a finalidade do contato entre cliente e serviço fornecido, apliquei os conhecimentos necessários para esse tipo de site, usei de uma necessidade real para criação de portfólio e meu currículo profissional.

## Tecnologias
- HTML5
- Bootstrap 5.3
- CSS personalizado
- JavaScript com módulos ES
- Classes e separação de responsabilidades

## Estrutura
- `index.html`: estrutura da página.
- `css/styles.css`: identidade visual.
- `js/app.js`: inicialização da aplicação.
- `js/config.js`: número do WhatsApp.
- `js/models/Appointment.js`: modelo de agendamento.
- `js/services/Services.js`: serviços de WhatsApp e galeria.
- `js/components/Navigation.js`: comportamento do menu.
- `assets/images/hero.png`: imagem principal.
